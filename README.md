# GAMA-1 Capture & Proposal Library

GAMA-1 Technologies, LLC uses this library to win federal IT work faster. It holds reusable, evaluator-ready content for capture, proposals, and RFI responses. Every file follows one style: ASD-STE100, active voice, outcomes first, and standards-anchored.

## Structure

| Folder | Contents |
|---|---|
| [`00-company/`](00-company/) | Corporate profile, certifications register, teaming partners |
| [`01-capabilities/`](01-capabilities/) | Capability statements for eight service lines |
| [`02-past-performance/`](02-past-performance/) | Past performance template and NOAA anchor write-up |
| [`03-agencies/`](03-agencies/) | Agency mission, priorities, and voice-of-the-customer vocabulary |
| [`04-boilerplate/`](04-boilerplate/) | Reusable narrative blocks for common evaluation topics |
| [`05-templates/`](05-templates/) | Solicitation outline, SWOT/Go-No-Go, LCAT/LOE, POA&M, scoring rubric, RFI response |
| [`06-pipeline/`](06-pipeline/) | Active opportunity tracker |
| [`claude-config/`](claude-config/) | Shared Claude Code config and Obsidian sync setup for all machines |
| [`tools/`](tools/) | Utilities, including an offline meeting transcriber for Claude Desktop |
| [`CLAUDE.md`](CLAUDE.md) | Style guide and workflow rules for AI-assisted drafting |

## How to use

Start each pursuit with `05-templates/solicitation-outline.md`. Pull mission language from `03-agencies/`. Pull approach text from `04-boilerplate/` and `01-capabilities/`. Prove each claim with `02-past-performance/`. Score the draft with `05-templates/proposal-scoring-rubric.md` before color reviews.

## Content rules

Do not publish a metric, contract number, dollar value, or certification without a source in this repository. Placeholders appear as `[VERIFY]` or `[METRIC: source required]`. Resolve every placeholder before submission.

## Handling

This repository holds company-proprietary content. Keep it private. Do not store CUI, solicitation material marked source-selection sensitive, or pricing data from other offerors here.
