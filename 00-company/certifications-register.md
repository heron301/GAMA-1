## Wording rules

Write "GAMA-1 is ISO 27001 certified" only if a current certificate exists. Write "GAMA-1 operates an ISO 27001-aligned ISMS" if it does not. For CMMC, write "GAMA-1 completed a CMMC Level 2 self-assessment" unless a C3PAO certification exists. FedRAMP authorizes cloud services, not companies. Write "GAMA-1 accelerates FedRAMP authorization," not "GAMA-1 is FedRAMP certified."
