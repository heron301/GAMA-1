# LCAT / LOE Estimating Guide

Use `lcat-loe.csv` as the starting sheet. Compute Hours = FTE x Hours_per_FTE_Year for each year.

Default productive hours: 1,880 per FTE per year (2,080 less holidays and leave). Use the solicitation's figure if it states one (some use 1,920). Record the basis in the Notes column.

Map every task to a PWS paragraph. Map every LCAT to the GSA MAS or vehicle labor category description. Confirm each named person meets the LCAT education and experience minimums.

Build a base year plus four option years. Apply escalation in the price model, not in the hours. Show teammate workshare in the Performer column so you can test FAR 52.219-14 limits when relevant.

Compare the total against the IGCE or historical award value. Explain any variance above 15%.
