# Boilerplate: IT Service Management (ITIL 4 / ISO 20000)

[AGENCY] users need fast, reliable support so they can focus on the mission. GAMA-1 delivers service management under ITIL 4 and an ISO 20000 aligned service management system.

We run incident, request, problem, change, and knowledge practices in ServiceNow. We measure each practice against agreed service levels. We publish a monthly performance report to the COR. We use problem management to find and remove root causes. We grow a knowledge base so users resolve common issues through self-service.

We apply continual improvement each month. We review trends, rank improvement actions, and track them to closure. [AI/ML: virtual agents resolve routine requests, and machine learning routes tickets to the right resolver group.]

The result for [AGENCY] is higher first-contact resolution, shorter outages, and higher user satisfaction.
