# Boilerplate: Section 508 Accessibility

Every [AGENCY] user must have equal access to information and services. GAMA-1 builds accessibility in from the first design sprint.

We conform to the Revised Section 508 Standards (36 CFR 1194), which adopt WCAG 2.0 Level AA. We test with automated tools and with manual assistive technology tests. We use the ICT Testing Baseline for Web Accessibility. We fix defects before release and publish an Accessibility Conformance Report (VPAT) for each product.

The result is accessible products and lower legal and reputational risk for [AGENCY].
