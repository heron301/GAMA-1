# Cloud Services

## Outcome

GAMA-1 moves workloads to the cloud without disruption to the mission. Agencies gain elastic capacity, lower hosting cost, and an authorization-ready landing zone.

## Approach

We assess each workload for cloud fit, cost, and data sensitivity. We build a secure landing zone as infrastructure as code. We inherit controls from FedRAMP-authorized services to reduce the agency's control burden. We migrate in waves with rollback plans and parallel operation. We support AWS, Azure, and Google Cloud, plus hybrid on-premises designs. We apply FinOps practice to track and cut spend after migration.

## Standards and frameworks

| Area | Standard |
|---|---|
| Authorization | FedRAMP Moderate / High, agency ATO |
| Architecture | AWS Well-Architected, Azure CAF, Google Cloud Architecture Framework |
| Migration | AWS Migration Acceleration Program (MAP) |
| Network security | TIC 3.0 cloud use cases, NIST SP 800-207 |
| Policy | Federal Cloud Smart strategy |
